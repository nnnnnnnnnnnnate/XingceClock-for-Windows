行测计时器 —— 使用说明
========================================

【这是什么】
一个给自己用的倒计时工具:一串"闹钟"(每项 = 名称 + 分钟数),
可以单独跑其中一项,也可以按清单顺序整串"流水线"走完,
每段到点自动响铃。默认清单按行测整卷 120 分钟配好,
所有名称和时长都可以随意改。

【怎么用】
1. 双击"行测计时器.exe"打开。
2. 主界面是闹钟清单:
   - 双击某一项 = 直接单独开始这一项的倒计时;
   - 选中某一项后,可点"修改 / 删除 / 上移 / 下移";
   - 点"添加"可以增加新的一项;
   - "单独走选中项"按钮 = 开始选中的那一项;
   - "流水线整串走完"按钮 = 按顺序从第一项走到最后一项,
     每段结束响铃 5 秒后自动进入下一段(期间可点"立即开始下一项")。
3. 计时窗口永远置顶在屏幕最前,不受你切到别的窗口影响。
   窗口里有 暂停/继续、跳过本段、停止 三个按钮。
4. 到点会循环响铃(用 Windows 自带闹钟音效),
   点按钮即可停止铃声。

【数据存在哪】
清单保存在本文件夹的 stages.txt 里(一行 = "名称 + Tab + 分钟数")。
想手动备份或编辑都可以;把这个文件删掉,下次打开会恢复默认清单。

【改了代码想重新编译】
双击本文件夹里的 build.bat 即可(用的是 Windows 自带编译器,
不需要联网、不需要装任何东西)。

【常见问题】
- 第一次运行如果 Windows 弹出"已保护你的电脑"(SmartScreen),
  点"更多信息"→"仍要运行"即可,这是对来路不明程序的通用提醒。
- 计时基于电脑的系统时钟:如果中途电脑休眠,恢复后按真实
  经过的时间计算(相当于真实考试钟,不走慢)。
